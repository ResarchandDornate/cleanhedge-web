# CleanHedge Website

Official website for CleanHedge.

## Structure

- `index.html`: Main landing page
- `about-us.html`: About CleanHedge
- `bess.html`: Battery Energy Storage Systems (BESS)
- `solar-rooftop.html`: Solar Rooftop Solutions
- `solar-inroof.html`: Solar Inroof Solutions
- `open-access.html`: Open Access Power Solutions
- `green-certification.html`: Green Energy Certification
- `team-members.html`: Team overview
- `contact.html`: Contact and inquiries
- `assets/`: Styling, scripts, fonts, and images
- `package.json`: Project configuration and static serving scripts
